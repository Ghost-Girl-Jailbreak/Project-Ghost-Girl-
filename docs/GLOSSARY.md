# Glossary

Terms you'll see around Project Ghost Girl and the Xbox 360
homebrew scene.

---

## Console Revisions

| Term | Meaning |
|---|---|
| **Xenon** | First Xbox 360 revision (Phat) |
| **Zephyr** | Second Phat revision |
| **Falcon** | Third Phat revision |
| **Jasper** | Fourth Phat revision, more reliable |
| **Trinity** | First Slim revision |
| **Corona** | Second Slim revision |
| **Winchester** | Final Slim revision, hardest to exploit |

---

## Exploits

| Term | Meaning |
|---|---|
| **RGH** | Reset Glitch Hack — hardware mod |
| **JTAG** | Older hardware exploit for Phat consoles |
| **ABadUpdate** | Modern software exploit |
| **ABadAvatar** | Modern software exploit, sibling of ABadUpdate |
| **Softmod** | Modding without hardware changes |
| **Jailbreak** | General term for freeing a console from restrictions |

---

## Files & Formats

| Term | Meaning |
|---|---|
| **.xex** | Xbox 360 executable format |
| **.elf** | Generic executable format, used by LibXenon |
| **repo.ini** | Project Ghost Girl's master manifest |
| **GhostGirlRepack.zip** | The softmod package users download |
| **GhostGirl.xex** | The client app running on the console |

---

## Tools & Dashboards

| Term | Meaning |
|---|---|
| **Aurora** | Popular custom dashboard |
| **DashLaunch** | Runtime patcher for RGH consoles |
| **XeXMenu** | File browser and homebrew launcher |
| **XeLL** | Bootloader used in some setups |
| **LibXenon** | Open-source homebrew library for 360 |
| **XDK** | Official Microsoft Xbox 360 Development Kit |

---

## Project Ghost Girl Terms

| Term | Meaning |
|---|---|
| **Client** | The `GhostGirl.xex` app running on your console |
| **Manifest** | The `repo.ini` file listing available apps |
| **App** | A homebrew program listed in the store |
| **App Repo** | A GitHub repo holding one app's files |
| **Vote Issue** | GitHub issue used for console vote counting |

---

## Other

| Term | Meaning |
|---|---|
| **Phat** | Original 2005-2010 Xbox 360 |
| **Slim** | 2010-2013 Xbox 360 S |
| **E** | 2013 Xbox 360 E, final model |
| **HDD** | Internal hard drive |
| **USB** | External storage via USB port |
| **FAT32** | File system most 360 exploits require |
