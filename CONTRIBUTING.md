# Contributing to Project Ghost Girl

Thanks for your interest — but please read this first.

## License Notice

Project Ghost Girl is **proprietary**. All rights reserved.
By contributing, you agree that your contributions become the
property of the project owner.

**This is not an open-source project.** Do not submit code
expecting it to remain your own.

## What We Accept

- Bug reports via GitHub Issues
- Feature suggestions via GitHub Issues
- Votes for future console support via the voting issues

## What We Do NOT Accept

- Pull requests modifying source code without prior permission
- Forks intended for redistribution
- Reuploads of the client or any `.xex` files

## Reporting Bugs

Use the bug report template. Include:
- Console model and exploit (ABadUpdate / ABadAvatar)
- Client version
- Steps to reproduce
- What you expected vs. what happened

## Suggesting Features

Open an issue with the `enhancement` label. Be specific.
