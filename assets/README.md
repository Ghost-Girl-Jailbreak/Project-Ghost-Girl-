# Assets

Images and media used in Project Ghost Girl documentation and
release posts.

## Files

| File | Purpose |
|---|---|
| `banner.png` | Main README header (if used as static fallback) |
| `logo.png` | Small logo, used for social preview |
| `social-preview.png` | 1280x640 preview image for GitHub shares |
| `screenshots/` | Client UI screenshots (coming soon) |

## Guidelines

- Keep file sizes reasonable (under 500KB per image where possible)
- Use PNG for graphics with transparency
- Use JPG for screenshots
- Follow the brand colors from `docs/DESIGN.md`

## Social Preview

Upload `social-preview.png` in:
Repo Settings → General → Social preview → Upload image

Recommended size: **1280 x 640 px**
