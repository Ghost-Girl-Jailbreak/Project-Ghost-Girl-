# Support

How to get help with Project Ghost Girl.

---

## Before You Ask

Do these first — 90% of questions are already answered:

1. **Check the [FAQ](FAQ.md)**
2. **Check the [Troubleshooting section](TUTORIAL.md#troubleshooting)**
3. **Search existing [GitHub Issues](../../issues)**
4. **Search the Discord `#help` channel history**

If none of those solve it, continue below.

---

## Where to Ask

| Question Type | Where |
|---|---|
| Bug report | [GitHub Issues](../../issues) with `bug` label |
| Feature request | [GitHub Issues](../../issues) with `enhancement` label |
| Softmod help | Discord `#help` channel |
| Console voting | GitHub vote issues |
| General chat | Discord `#general` channel |

---

## What to Include

When reporting a problem, always include:

- **Console model and revision** (Trinity / Corona / Winchester / etc.)
- **Exploit** (ABadUpdate / ABadAvatar)
- **Version** of GhostGirlRepack
- **What you did** — steps to reproduce
- **What you expected** to happen
- **What actually happened**
- **Any error messages** (screenshots help)

---

## Response Times

This is a hobby project. There is no guaranteed response time.

- **GitHub Issues:** usually within a few days
- **Discord:** faster, but depends on who's online
- **Urgent security issues:** see [SECURITY.md](../SECURITY.md)

---

## What We Don't Support

- Stock / unmodded consoles
- RGH / JTAG consoles (not yet)
- Third-party apps not listed in the store
- Piracy-related questions
- Modded consoles bricked by other tools

---

## Community Support

Other users in Discord often know the answer faster than the
maintainers. Don't hesitate to ask in `#help` — the community
is friendly and active.
