## Console Revisions Explained

| Revision | Notes |
|---|---|
| **Trinity** | First Slim revision, most reliable for softmods |
| **Corona** | Later Slim revision, common revision |
| **Winchester** | Final Slim revision, harder to exploit |
| **Xenon / Zephyr / Falcon / Jasper** | Original Phat consoles |
