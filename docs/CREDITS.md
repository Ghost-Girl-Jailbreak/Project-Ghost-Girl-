# Credits

Project Ghost Girl exists thanks to a lot of tools, projects, and
people in the homebrew scene. This page is here to say thank you.

## Built With

- **Xbox 360 XDK** — official Microsoft toolchain
- **GitHub** — free hosting for the client, manifest, and app repos
- **capsule-render** — animated header/footer banners
- **readme-typing-svg** — animated typing text
- **shields.io** — status badges

## Inspiration

- **FitGirl Repacks** — branding style and naming convention
- **Xbox 360 Homebrew Store** — proof that an on-console store works
- **Aurora Dashboard** — script-based store layout
- **Omni360** — archive.org integration concept

## Scene Tools

- **XeXMenu** — file browsing and launching homebrew
- **DashLaunch** — runtime patching on RGH consoles
- **XeLL** — bootloader used in many setups

## Special Thanks

- The Free60 project for open Xbox 360 documentation
- The homebrew community for keeping the scene alive
- Everyone who voted on future console support

## Want to Be Listed?

If you contributed something that ended up in Project Ghost Girl
and you're not listed here, open an issue and we'll add you.
